# Как не выглядеть «клоном» romedov.by для Google и Яндекса

**Одинаковые title, description и абзацы** — главный сигнал дубля. Общая **гамма** и схожая вёрстка — нормально; на tehmehcomplex.ru свой бренд **TMK / ТехМехКомплекс**.

## Обязательно (уже заложено в romedov.ru)

| Что | romedov.by | romedov.ru |
|-----|------------|------------|
| Домен и canonical | `romedov.by` | `tehmehcomplex.ru` |
| Юрлицо, ИНН/ОГРН, банк | РБ | ООО «ТехМехКомплекс», Смоленск |
| Телефон, email | +375… | +7…, info@tehmehcomplex.ru |
| Гео производства | Борисов | Смоленск, другие координаты карты |
| Schema.org | `ru-BY`, areaServed BY | `ru-RU`, areaServed RU |
| Meta title/description главной | Свои формулировки | Другие формулировки |
| Кейсы | Минск, Борисов, Гомель | Другие города и цифры |

## Переписать вручную (рекомендуется перед индексацией)

1. **Каждая страница `/production/*`** — уникальные `title`, `description`, 1–2 абзаца в `equipment-seo.ts` (не только замена «Борисов → Смоленск»).
2. **Кейсы** — другие заголовки, сроки, города; по возможности **свои фото**.
3. **Hero и блок «Почему мы»** — другой порядок мыслей и синонимы, не копипаст.
4. **OG-картинки** — после правок текста: `npm run generate:og`.

## Не делать

- `rel=canonical` на .by с .ru.
- Сквозные одинаковые тексты на 10+ URL.
- Один и тот же alt у всех фото на обоих сайтах.

## hreflang

Нужен только если это **одна компания, два региона** и вы хотите связать версии. Для **разных юрлиц** обычно **не** связывают hreflang — достаточно разного контента и реквизитов.

## Проверка перед запуском

- [Text.ru](https://text.ru) / Advego — уникальность главной и 2–3 production-страниц относительно .by (цель **>70%**).
- Яндекс.Вебмастер / Google Search Console — отдельные свойства на каждый домен.
